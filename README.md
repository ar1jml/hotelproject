# Soljam — Full-Stack Hotel Management & Booking System

Soljam is a full-stack hotel management and booking platform.

## Stack

### Frontend
- Vue.js
- Vite

### Backend
- FastAPI
- Python
- SQLAlchemy
- Pydantic
- asyncpg

### Database
- PostgreSQL 16
- Docker

## Architecture

Vue.js
   ↓
FastAPI REST API
   ↓
SQLAlchemy Async
   ↓
PostgreSQL
